# 🀄 3D 리치 마작 (Riichi Mahjong 3D)

Web Browser 기반의 풀 3D 일본 리치 마작(Japanese Riichi Mahjong) 게임입니다. Three.js를 사용한 실감 나는 3D 작탁 환경과 정통 일본 마작 룰 엔진, P2P WebRTC 실시간 온라인 멀티플레이어 대전, 초보자를 위한 단계별 입문 튜토리얼을 지원합니다.

---

## 🌟 주요 기능 (Features)

### 1. 실감 나는 3D 그래픽 & 작탁 연출 (Three.js WebGL)
- **절차적 타일 텍스처 렌더링**: 수패(만수/통수/삭수), 자패(동남서북백발중), 적도라(아카도라 반짝임 효과) 등 고화질 텍스처 실시간 캔버스 생성.
- **중앙 전자 디스플레이(작탁 계기판)**: 현재 국(동/남), 본장(本場), 남은 패산 개수, 공탁금(리치봉)을 실시간 디스플레이.
- **3D 카메라 시점 전환**: `1`, `2`, `3` 키 또는 `Space` 키로 자유로운 시점 전환 (내 시점, 탑뷰, 전체 대국 시점).
- **타패 및 조패 어시스트**: 마우스 호버 시 자연스러운 패 들림 효과, 텐파이 유지 타패 사전 강조(Y축 살짝 들림).
- **다이내믹 후로(울기) 배치**: 치(Kamicha), 퐁/대명깡(상대 위치별 패 회전), 안깡/가깡 3D 배치 및 후로 횟수별 패산 겹침 방지 오프셋.

### 2. 정통 리치 마작 룰 심판 엔진
- **경기 모드**: 단기 속공 **동풍전 (東風戦)** 및 정통 표준 **반장전 (半荘戦)**.
- **완벽한 역(役) 판정 및 점수 계산**:
  - 리치, 더블 리치, 일발(일발 지우기 판정 포함), 멘젠 츠모, 탕야오, 핑후, 역패, 삼색동순, 일기통관, 또이또이, 치또이츠 등 1~2판 역.
  - 혼일색, 청일색, 소삼원, 산안커, 삼색동각, 산깡즈 등 상위 역.
  - 국사무쌍, 사암각, 대삼원, 자일색, 녹일색, 구련보등, 사깡즈 등 역만(役満) 및 더블 역만.
  - 부수(符) 및 판수(飜)에 따른 정밀 점수 계산 (만관, 하네만, 배만, 삼배만, 역만).
- **특수 룰 & 유국 판정**:
  - 후리텐(진청) 정밀 판정: 일반 버림패 후리텐, 동순 후리텐, 리치 후 후리텐.
  - 황패유국(荒牌流局) 및 노텐 벌부(1,000~3,000점) 정산.
  - 구종구패(九種九牌) 유국 선언.
  - 연장(렌찬) 및 오야(친) 교대 로직.
  - 쿠이카에(울어 바꾸기) 방지 및 쵼보 예방.

### 3. P2P WebRTC 실시간 온라인 멀티플레이어 (PeerJS)
- **간편한 4자리 방 코드**: 별도의 무거운 게임 서버 없이 P2P WebRTC를 통해 방 생성 및 4자리 코드로 즉시 접속.
- **유연한 인원 매칭**: 1~4인 자유 대전 가능 (빈자리는 AI 봇이 자동으로 참가하여 언제든 대국 가능).
- **실시간 대기방(로비)**:
  - 자리 배치 및 바람(동/남/서/북) 확인.
  - 전원 준비 완료 확인 후 방장 게임 시작.
  - 대기방 실시간 입장/퇴장/강퇴 공지 배너.
- **무결점 즉각 이탈 감지 및 AI 자동 전환**:
  - `beforeunload` / `pagehide` 브라우저 종료 이벤트 및 다중 WebRTC 상태 감시.
  - 대국 중 상대가 탭을 닫거나 나갈 경우, 대국이 멈추지 않고 **즉시 AI로 전환되어 끊김 없이 대국이 자동 진행**.

### 4. 인터랙티브 초보자 튜토리얼 (1~6장)
- **제 1 장**: 기본 손패 구조(4몸통 1머리)와 리치 화료
- **제 2 장**: 외톨이 자패 정리와 쯔모 화료
- **제 3 장**: 스피드 속공! 울기(치·퐁·깡)와 역 없음 방지
- **제 4 장**: 필수 족보 마스터 (탕야오 / 자패 역패 / 핑후)
- **제 5 장**: 후리텐 방지와 방총(쏘임) 체험 & 시간 되돌리기 수비 실습
- **제 6 장**: 실전 모의 대국 (플레이어 전용 화료 룰로 편안한 실전 연습)

## 🚀 실행 방법 (Quick Start)

본 프로젝트는 순수 프론트엔드 Web 기술(HTML5, CSS3, JavaScript, WebGL)로 제작되어 별도의 복잡한 설치 없이 바로 실행할 수 있습니다.

### 방법 1. Windows 배치 파일로 바로 실행 (가장 간편)
프로젝트 폴더에서 `start_game.bat` 파일을 더블 클릭하면 로컬 웹 서버가 실행되고 기본 브라우저가 자동으로 열립니다.

```bash
# 또는 터미널에서:
python run_game.py
```

### 방법 2. Node.js npx를 사용하는 경우
```bash
npx serve .
# 또는
npx http-server .
```

### 방법 3. VS Code Live Server 확장 사용
`index.html` 파일을 우클릭한 후 **"Open with Live Server"**를 클릭하여 실행합니다.

## 🧪 테스트 실행 (Test Suite)

마작 점수 계산, 샹텐 분석, 역 판정 무결성을 검증하는 자동화 테스트 스위트가 포함되어 있습니다.

```bash
node run_tests.js
```

5. 수 분 내로 발급되는 배포 URL(`https://<username>.github.io/<repo-name>/`)로 접속하여 게임을 플레이할 수 있습니다.
